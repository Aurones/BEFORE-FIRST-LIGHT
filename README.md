# До первого света (BEFORE-FIRST-LIGHT)

Техническая основа браузерной игры для iPhone. Проект использует HTML, CSS и JavaScript без сборки и сторонних зависимостей.

- `index.html` содержит экран игры.
- `styles.css` учитывает динамическую высоту окна Safari и безопасные зоны экрана.
- `main.js` служит точкой входа для будущей игровой логики.

## Локальный запуск

В корне проекта запустите `python3 -m http.server 8000` и откройте `http://localhost:8000/`.

## Бесплатная публикация на GitHub Pages

1. Поместите файлы в корень ветки `main` публичного репозитория `BEFORE-FIRST-LIGHT`. Включите файл `.nojekyll`.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
3. После публикации откройте адрес из **Settings → Pages**. Обычно он имеет вид `https://<владелец>.github.io/BEFORE-FIRST-LIGHT/`.

Относительные пути к CSS и JavaScript поддерживают размещение проекта в подкаталоге GitHub Pages.
